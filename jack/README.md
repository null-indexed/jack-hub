# Jack's notebook

This folder is yours. Everything you write here shows up on your website, on the matching page, about a minute after you save.

| File | Shows up on |
|---|---|
| `workshop-log.md` | The Workshop (tinkering, rebuilds, modding) |
| `ai-log.md` | AI roadmap |
| `builds.md` | Things I've built |

## How to add something

1. Open the file on GitHub and press the pencil icon (top right of the file).
2. Type your entry. Newest at the top is easiest to read later.
3. Press **Commit changes**, add a short note about what you changed, then **Commit changes** again.
4. Wait about a minute, then refresh your site.

Made a mess? Nothing is lost. Every save is kept in the history, so Dad can roll it back.

## Adding a photo

1. In this folder press **Add file**, then **Upload files**, and drop your photo in a `photos` folder (type `photos/` before the name).
2. In your notes, write `![what it shows](photos/your-photo.jpg)`.

Keep photos of the device, not of people, and crop out serial numbers and stickers with codes on.

## Writing cheat sheet

```
## A heading
Normal text is just typed. Leave an empty line between paragraphs.
**bold**   _italics_   `code or a command`
- a bullet point
- [ ] something to do
- [x] something done
[link text](https://example.com)
---   (a line across the page)
```

## The one rule

This site is public. Anyone with the link can read it. No surname, address, passwords, phone numbers or photos of people. If in doubt, ask Dad first.
