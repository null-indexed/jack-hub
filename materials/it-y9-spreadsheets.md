# Advanced spreadsheets

BTEC Tech Award in Digital Information Technology, Year 9, Autumn. Leads into Component 2 (Collecting, Presenting and Interpreting Data).

## Skills to be confident with

- Absolute vs relative cell references ($A$1 vs A1)
- SUM, AVERAGE, MIN, MAX, COUNT, COUNTIF
- IF, and nested IF
- VLOOKUP or XLOOKUP
- Conditional formatting
- Data validation (drop-down lists, rules)
- Sorting and filtering
- Charts: choosing the right one for the data
- Named ranges

## Your build task

Make a spreadsheet tracking something real: football scores, a game's stats, pocket money, anything with at least 20 rows.

Requirements:

1. A lookup table on a second sheet, used by VLOOKUP or XLOOKUP
2. At least one IF formula that labels rows (for example "over budget" or "win")
3. Conditional formatting that highlights something important
4. A drop-down list using data validation
5. One chart, with a title and labelled axes
6. A short note explaining what the data shows

If a formula breaks when you copy it down, that's an absolute vs relative reference problem. Work out which.

## Self-test questions

1. What does $B$2 do differently from B2 when copied?
2. When would you use COUNTIF instead of COUNT?
3. Why is a pie chart a bad choice for data that changes over time?
4. What does data validation protect against?
